# HAKO

写真・動画・音声・ファイル・気になったサイトを、**暗号化して自分の端末だけ**にしまっておくWebアプリ。サーバーなし・GitHub Pagesで動く。

## 置き方（iPhoneのSafariだけでOK）

1. GitHubで新しいリポジトリを作る（例：`hako`）。**Private推奨**（Pagesを使うにはPublicかProプラン。中身はコードだけで、写真などのデータはGitHubに一切上がらない）
2. 「Add file → Upload files」で、このzipの中身を**全部そのまま**アップロード
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に `https://ユーザー名.github.io/hako/` を開く
5. 共有ボタン → **「ホーム画面に追加」** → ホーム画面のアイコンから開く（これ大事。Safariのタブのままだと、iOSがしばらく使わなかったデータを消すことがある）

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | 画面 |
| style.css | デザイン |
| ui.js | アイコン・シート・通知などの部品 |
| crypto.js | 暗号化（AES-256-GCM / PBKDF2 31万回） |
| db.js | 端末内の保存（IndexedDB） |
| zip.js | ZIPの作成・読み込み |
| media.js | 取り込み・サムネ・ダウンロード・書き出し・バックアップ |
| app.js | 画面の動き全部 |
| sw.js | オフラインで開けるようにする |
| manifest.json / icon-*.png | ホーム画面アプリ用 |
| proxy-worker.js | （任意）自分用プロキシ。GitHubには置かなくていい |

## できること

- **暗号化保管庫**：パスワードで開く。中身（写真・動画・名前・メモ・タグ・サイト一覧まで）全部暗号化。端末を調べられても中身はわからない
- **Face ID**：設定 → セキュリティ →「Face IDで開く」。非対応端末なら、パスワードをiPhoneの「パスワード」アプリに保存すればFace IDで自動入力できる
- **ライブラリ**：写真と動画は同じ場所。ジャンル（上のタブ）・フォルダ・タグ・お気に入り・種類で絞り込み、名前順/追加順/サイズ順など
- **ビューア**：左右スワイプ／画面の端タップで移動、`3 / 10` 表示、縦長画像はスクロール、ダブルタップで拡大
- **閉じても再生**：動画・音声は「閉じても再生」でミニプレーヤーへ。アプリ内を移動しても止まらない。動画はPiPも可
- **容量を空ける**：長押し →「容量を空ける」で本体だけ消して再ダウンロード待ちに。**サムネ・名前・タグ・メモは残る**（真っ白にならない）。URLから入れたものは再ダウンロードで、それ以外は「ファイルを選んで戻す」で戻る
- **動画のサムネ**：再生中に「この場面をサムネに」、または詳細 →「サムネを選ぶ」でスライダーから。再ダウンロードしても変わらない
- **音声のカバー**：HAKOに入れた画像か端末の画像から選べる
- **URLから**：貼るとすぐダウンロード。複数同時OK。ページのURLなら画像・動画を探して一覧 → チェックで選ぶ → 番号付きで1つのフォルダに
- **まとめて書き出し**：選択 →「書き出す」で1つのZIP、「個別に保存」で写真アプリへ
- **保存先を選べる**：HAKOの中（暗号化）か、iPhoneのファイルへ
- **バックアップ**：設定 → データ。暗号化されたまま1つのZIP。iCloud Driveに置いて、新しい端末の最初の画面「別の端末のバックアップから復元する」で移せる
- **サイト**：ジャンルのタブごとに登録。タグ・メモ・お気に入り
- **オフラインモード**：右上のボタンで切替。ONの間は一切通信しない
- **ゴミ箱**：消したものは自分で空にするまで残る

## バックアップの使い方（PCに置いて、見る時だけスマホに戻す）

1. 設定 → データ →「バックアップを書き出す」→ ZIPをPCへ送る（AirDrop・iCloud Driveなど）
2. HAKOでフォルダや写真を選んで「容量を空ける」→ iPhoneが軽くなる（サムネ・名前・タグは残る）
3. 見たくなったら、そのZIPをiPhoneに戻す（AirDropやiCloud Drive）→ 設定 →「バックアップを読み込む」
4. **戻すフォルダを選べる**ので、見たい分だけ戻せばいい。戻したらiPhone側のZIPは消してOK（PCの分は残しておく）

新しいiPhoneに移す時は、最初の画面の「別の端末のバックアップから復元する」でZIPを選ぶ。

## v1.2で追加したもの

- **ウイルス・変なファイル対策**：実行ファイル・スクリプト・Webページ・マクロ付きOfficeなどは🛡「隔離」。HAKOの中では実行も表示もせず、テキストとしてだけ見られる。書き出す時は警告が出る。ページ全体に「自分のファイル以外のスクリプトを読まない」設定（CSP）を入れて、保存データを流す時も「解釈しない・実行しない」指定にしてある
- **書き出す写真から位置情報を消す**：JPEGの位置情報・機種・撮影日時などを消して書き出す（向きは保つ）。中の元データとバックアップはそのまま
- **バックアップから選んで戻す**：フォルダ単位で戻すものを選べる
- **自分で決めた順**：選択 →「先頭へ」「末尾へ」、長押し →「1つ前へ / 1つ後へ」
- **連番で名前**：選んだものを「旅行_001.jpg」のように並び順で一括リネーム
- **重複を探す**：中身が同じものを見つけて選択（古いほうは残す）
- **同じ名前の扱い（v1.2.1）**：中身が違うのに名前が同じものは、後から入ったほうを「名前 (2).jpg」に自動で番号付け。既に並んでる分は設定 →「今ある同じ名前を整理」
- **重複の扱い（v1.2.1）**：中身が同じものはスキップ。ただし容量を空けてあるものと同じなら、スキップせずにその本体として戻す（URL・ファイル・バックアップどれでも）。バックアップを合わせる時も中身で重複を見る。同時ダウンロード中の同じ中身もぶつからない
- **パスワードを5回間違えると待ち時間**（30秒から倍々、最大1時間）

## v1.1で追加したもの

- **GB級でも速く・重くならない**：大きい動画・音声は「見る部分だけその場で復号して流す」方式（sw.js）。開いてすぐ再生・シークできて、メモリにまるごと読み込まない。URLからのダウンロードも、届いた分から順に暗号化して保存するのでGBでも溜め込まない。大きい書き出し・バックアップも少しずつ作って流す（1つのZIPは4GBまで、超えたら自動で分割）。取り込みは4並列で暗号化
- **IPを相手サイトに見せない**：設定 → ネット。ONにすると、ダウンロードもプレビューもアイコンも必ず自分用プロキシ経由（相手に残るのはCloudflareのIP）。直接は絶対に取りに行かない
- **追跡用パラメータの除去**：サイトのURLから utm_〜 / fbclid などを消す
- **自動更新確認のOFF**：開くたびにGitHubへ問い合わせない（手動の「今すぐ更新を確認」あり）
- **中身チェック**：拡張子じゃなく中身で判定。「.jpgなのに実はWebページ」（直リンク禁止で返ってくるやつ）は保存しないで理由を出す。拡張子と中身が違うものは「!」マーク
- **重複スキップ**：中身が同じファイル・同じURLは取り込まない
- **続きから再生**：長い動画・音声は止めた位置を覚える
- **再生速度**（0.75〜2x）、**スライドショー**
- **アルバム表示**：フォルダを表紙付きで並べる。長押しメニューから表紙を選べる
- **作成日（撮影日）順**の並べ替え
- **データ点検**：本体がそろってるか・復号できるかを確認。問題があれば印を付けて「再DL待ち」扱いにする（消さない）
- **バックアップのお知らせ**：一定日数バックアップしてないと知らせる

## IP・ログについて

| 誰 | 何が見える | 対策 |
|---|---|---|
| 相手サイト | 取りに行った通信とIP | 「IPを相手サイトに見せない」ON＋自分用プロキシ |
| Cloudflare | 中継した通信 | Workerはログを書かない。Logs/ObservabilityはOFF。Worker名に本名やIDを入れない |
| GitHub | アプリを開いた・更新した | 「自動更新確認」OFF（ブラウザ自体の1日1回程度の確認は止められない） |
| HAKO | なし（サーバーがない） | — |
| Safariでサイトを開く時 | 自分のIP | VPNアプリ（Alohaの内蔵VPNと同じ役割） |

## Alohaみたいに直接保存したい時

Alohaはアプリ本体がブラウザなので制限なく落とせる。HAKOはSafariの中のWebアプリなので、他サイトから直接取るのをブラウザが止める。プロキシを使わずに直接落としたいなら、iPhoneの「ショートカット」で保存 → HAKOの「ファイルアプリから」で取り込むのが一番近い（手順は設定画面の下のほう）。

## ブックマークレット（ページの画像をまとめて拾う）

設定の一番下にコピーボタンと手順あり。JavaScriptで画像を出すサイト（スクロールで読み込むタイプ）でも、表示済みの画像を拾える。拾ったURL一覧を ＋ のURL欄に貼るとチェック画面が出る。

## 自分用プロキシ（任意）

多くのサイトは、他のサイトから直接ファイルを取ることをブラウザの仕組み（CORS）で禁止してる。HAKOで「直接ダウンロードを許可していない」と出たら、`proxy-worker.js` の先頭の手順でCloudflare Workers（無料）に置いて、設定 → ネット にURLとキーを入れる。

## できないこと

- 他のサイトの中の広告ブロック／ダウンロードボタンの横取り（ブラウザが禁止）→ Safariのコンテンツブロッカーとブックマークレットで代わりにする
- 写真アプリやファイルアプリの元データを消す（Webアプリには権限がない）
- YouTubeなどの配信型動画、ログインが必要な画像の取得
- 相手サイトに記録を一切残さない保証（取得の通信は必ず相手に届く。IPはプロキシで隠せる。Cookie・参照元は送らない）
- 端末をまたいだ自動同期（バックアップZIPで移す）
- iPhoneが再生できない形式（mkv・avi等）の再生、動画の圧縮
- 大きいファイル用の流す方式は、iPhone実機での速さ・動作は未検証（うまくいかない時は通常の方式に自動で戻る）
- **パスワードを忘れたら復元不可**（そういう設計）

## 更新するとき

ファイルを全部上書きアップロードする。`sw.js` の `VERSION` が上がってるので、開き直すと新しい版になる（設定 →「今すぐ更新を確認」でも可）。データは消えない。
